    Smooths noise while preserving a natural-looking falloff from nearby pixels.

    For blur filters, the kernel is the square neighborhood used around each pixel. A 3×3 kernel checks 9 neighbors; 9×9 checks 81. Larger kernels take more work and usually create a broader blur.

    What do the filters do?

    Gaussian blur: weighted smoothing; nearby pixels count more. Box blur: averages an equally sized neighbourhood.

    Sharpen: emphasizes local contrast. Laplacian edge: highlights rapid intensity changes. Sobel edge: estimates horizontal and vertical gradients. Emboss: adds directional relief.

    Gaussian and box blur use the chosen kernel size. Sharpen, edge, Sobel, and emboss use fixed 3×3 kernels. Edge pixels use clamp-to-edge padding.

    What do you want to do?

    Apply the filter once with your chosen strategy. Compare the result with a sequential reference.

    Parallel strategy
    OpenMP assigns image rows to workers using static scheduling.
    Pixel channels
    Each output pixel reads only the original input, so pixels can be computed independently. The UI also runs a sequential reference for timing and exact-output verification.
    How to run this project

    1. In an MSYS2 UCRT64 terminal: cd backend, then make.

    2. In PowerShell at frontend/: python -m pip install -r requirements.txt, then python app.py.

    3. Open http://127.0.0.1:5000. The Flask UI calls the C++ executable; UCRT64's OpenMP runtime is added automatically when launching it.

    If MSYS2 is installed somewhere other than C:\msys64, set MSYS2_UCRT64_BIN to its ucrt64\bin folder before starting Flask.
